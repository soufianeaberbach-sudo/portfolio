## Digital search and compromise

Pixel Swan's silk-dress model has a confirmed CC BY 4.0 license and promising
morphology, but the official viewer could not produce a lawful new render here:
it returned an authentication error. No website poster was copied and no access
restriction was bypassed. Creative Tools' actual MD view was too small and showed
a different tailored outfit. Jurvetson's Digital Dress was a photographed
projection exhibit, not simulation. CGElves' preset was pattern UI, not a garment.
The old creator collection URL returned 404. Generative stock images were rejected.

No stronger suitable licensed render was obtained from the serious candidates.
The existing licensed robe is therefore retained, without recoloring or cropping,
as the explicitly permitted fallback. **It still breaks the neutral palette and
is not a convincing satin-dress development counterpart.** Final visual approval
must judge this compromise; passing tests does not resolve it.

## Motion and technical corrections

Independent sources share one viewing axis, not falsely registered silhouettes.
Editorial cuts keep a complete source visible; a restrained viewing-distance
settle replaces the old empty/faded intervals. The measured garment entry/return
still uses the unchanged public utility, with the lab's decoded-clone adapter.
Only genuine front/back source travel transforms a garment view.

Corrections found through code, browser and recording review:

- Optional image failure no longer disables the real garment. Unavailable
  movements disappear; a surviving flat or pattern remains accessible.
- Reference-only requests omit process imagery from the viewing DOM. A requested
  verified mode fails closed for this unverified reference.
- Entry/return epochs invalidate old decode and animation callbacks. Interrupting
  entry no longer steals focus; pointer return begins at the measured current clone.
- Resize and reduced-motion changes settle existing state. Canceled evidence-only
  retreats cannot close a newly re-entered reader.
- View/inspection actions settle interrupted arrivals rather than freeze invisible
  images or partially completed transforms. Direct actions update the stage hash.
- Inspection borrows the already decoded high-resolution image, then restores it
  on close; it avoids decoding a second 38MP copy.
- Whole-source Fit/Reset, bounded pan, pinch and keyboard inspection retain every
  edge. Resize restores the whole source while retaining its identity. Fixed
  readout space prevents wrap-induced canvas resizing. Raster zoom is bounded;
  geometry remains uniform, and SVG coordinate readouts are identified as SVG.

No new dependency, shader, perpetual animation, public match-cut edit, production
reference-data change or unrelated refactor.

## Mobile and visual critique

Phones retain a complete primary photograph and one readable evidence representation
at a time. Sketch framing is a deliberate window over paper margins, not a shrunk
comparison. The complete technical pair and whole pattern switch in the same field;
inspection provides native detail. Context, ownership, source links, continuation
and return remain readable. Touch controls retain 44px targets.

The six-size review checked hierarchy, integration, composition, rhythm, type,
interaction and mobile. The initial drawing was too slight: the measured paper
window increased its presence while preserving both silhouettes. The former small
flat made construction unclear: the drawing now leads at full reading scale.
Recorded fade gaps and contradictory comparison copy were removed. Clone decode,
interruption, fit/reset and resize issues were corrected and verified. A/E source
windows and original photo pixels remain intact. D's palette mismatch is retained
as an explicit limitation, not hidden with an effect.

## Truthful content modes and integration boundary

`storyContent` / `storyAssets` read the existing `Subject` generated by
`projectSubject`. References and lab fixtures never acquire owner history. Only
supplied sketch/illustration, flat/pattern and CLO fields create their corresponding
movements. Fit/iteration evidence is retained separately. No source falls back to
an unrelated example. Unit-only model inputs are not rendered or published as work.

`?mode=reference` and `?mode=verified` both show this reference's honest photo-only
experience. Default `examples` is the explicitly labelled independent-media lab.
The offline review bundle contains study assets; it is not a production reader.

**A complete verified owner story has not been visually validated:** none is
supplied. The selectors and media inspector are ready for supplied data, but real
project rendering, extra fit/handoff movements and separate photo-view assets must
be validated in the controlled integration task. Do not mistake this example-based
proof for a completed commercial case study.

Required owner evidence: linked final front/back photographs; original concept
sketch/illustration where available; that garment's technical flat and full pattern;
its genuine CLO/MD render with software/version provenance; real fitting images
and notes if available; actual project-specific technical documents and permissions.
Omit missing stages. Do not attach unrelated references or demo tech packs.

After art-direction approval, a separate integration plan must confirm one genuine
linked project, adapt the existing public reader using its Subject data, validate
conditional stages and view geometry, and run public continuity/device checks.
Reference-only garments retain their existing reader. Neither branch is to be
merged automatically. Integration approval is separate from design approval.
