## Direction and evidence contract

Keep one luminous viewing space; let the actual medium establish the visual
hierarchy. A/E preserve the selected reference's complete silhouette. A real
illustration owns B. C moves from the whole pattern to a closely readable drawing
from the **same MoMu study**. D shows a real digital garment, then a completely
separate photographic representation. E resolves on the genuine back.

Literal silhouette morphing was rejected: these are independent works. A larger
set of unrelated museum sheets was also rejected: one drawing, one matched
technical pair and one digital garment provide a clearer proof. No generic curve,
synthetic mesh, fake pattern assembly, invented fit result or fabricated project
history remains in V.

Only MoMu's flat and pattern are related. The Connolly drawing, CGElves robe and
champagne photograph do not belong to a shared project. Stage context, source
captions, persistent provenance, inspectors, PDF and manifest state this explicitly.
This demonstrates **presentation**, not this reference's development history.

## Inspection and mobile

Inspection begins with the **whole source fitted**, not a random zoomed crop.
Vector inputs retain their original viewBox geometry; raster sources retain
native resolution. Uniform zoom, bounded pan, touch pinch, Fit, Reset, keyboard
arrows / + / − / Home, a location readout, source/license links and clear exit
make document edges accessible. Reset restores the initial overview.

The first whole-sheet view establishes orientation. An intentional zoom then
shows actual sleeve annotations, notches and grain direction. The review includes
both states, so zoomed details cannot be mistaken for the default view.

Phone uses one primary representation at a time: full drawing, whole pattern,
full technical flat, digital render or complete reference. Essential context is
visible at 11–12px or larger, with readable headings and source distinctions.
No opacity-zero mobile information suppression, tiny side-by-side comparisons,
stacked document cards or extended blank scroll sequences. Inspector layout
allocates remaining height after real captions rather than assuming a fixed
header size. The position readout reserves two lines so zoom text cannot change
the canvas size.

## Incomplete future evidence

The lab's `?evidence=none`, `design` and `construction` modes exercise omitted
stages. These external examples are never assigned to a public Project. Future
integration must derive movements from `projectSubject`'s supplied and verified
origin/build data. No sketch means no sketch movement; no pattern means no
pattern sheet; a supplied flat can own construction alone; no simulation means
no digital stage. Reference-only garments keep honest front/back inspection.
CLO screenshots can use the same image/inspector path with truthful CLO source
labels; no interactive 3D capability or fit validation is inferred from a render.

## Verification and limits

Final executed results are recorded in [QA](review/rtw-art-direction-v/QA.md).
Six browser sizes: **1440×900, 1366×768, 1024×768, 768×1024, 430×932, 390×844**.
All source artifacts, review videos, attribution and proof are committed/published;
public Portfolio integration remains unauthorized.

Remaining limitations:

1. These independent licensed examples are not a complete real project history.
   Production still needs corresponding owner-supplied sketches, construction,
   simulation, fit and handoff evidence. No empty stages or invented claims.
2. The digital robe is an authentic **1000px still**, not a downloadable 3D viewer,
   CLO output or matching satin simulation. Extreme zoom reveals its resolution
   limit. Larger owner-supplied renders can use the same inspector.
3. Whole-pattern annotations necessarily need inspection on a phone. The source
   is a scalable vector; the initial overview preserves orientation, not tiny
   text readability at gallery scale. No stroke weights were artificially changed.
4. Chromium emulation is not physical-phone, Safari or measured 60fps certification.
   No powerful-device-only effect was added. Native transition recordings, real
   source stress tests and reduced-motion proof are supplied for visual approval.

**Stop here for independent visual approval. No PR, merge, deployment or public
integration is part of V.**
